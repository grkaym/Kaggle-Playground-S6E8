# Predicting Smartphone Addiction（Playground S6E8）

## Overview
**「2026年 Kaggle Playground シリーズ」へようこそ！**

これまでの Playground シリーズと同様の趣旨を引き継ぎ、コミュニティの皆さんが機械学習のスキルを磨けるよう、興味深く親しみやすいデータセットを提供し、毎月コンテストを開催していく予定です。

目標：スマートフォン依存症の予測。

## Evaluation
提出された結果は、予測確率と観測されたターゲットとの間のROC曲線下面積に基づいて評価されます。

### Submission File
テストセット内の各 ID について、「addicted_label」変数の確率を予測する必要があります。ファイルにはヘッダーを含め、以下の形式で記述してください。
```csv
id,addicted_label
691369,0.2
691370,0.3
691371,0.1
etc.
```
